# 📰 NewsMag – World News Web App

NewsMag is a React-based world news web application that fetches **real-time news** using the **NewsData.io API** and displays it category-wise with a clean, responsive, and user-friendly interface.

---

## 🚀 Features

- 🔹 Dynamic navbar with category switching  
  (Top, Business, Technology, Health, Science, Sports, Entertainment)
- 🌐 Real-time news fetching using NewsData.io API
- ⚛️ Built with React Hooks (`useState`, `useEffect`)
- ⏳ Proper loading and error handling
- 🖼️ Clean and responsive card-based UI using Bootstrap
- 🔗 “Read More” button redirects to the original news source

---

## 🛠️ Tech Stack

- **React.js**
- **Vite**
- **JavaScript (ES6+)**
- **Bootstrap**
- **NewsData.io API**
